Daily executive dashboard

Leadership needed a single daily snapshot of sales orders, shipments, quotes, contracts, and aircraft-on-ground (AOG) priority jobs, plus the detail behind each number.

Business Intelligence · Power BI

Operations, backlog & WIP report

Problem
Throughput, revenue, backlog, and work-in-progress cost were buried in raw work-order data, with no single view of what was shipping, what was stuck, and what open jobs were costing.
Approach
Built a three-page Power BI report on the work-order data: YTD / MTD KPIs and revenue against monthly goal; backlog split by constraint (awaiting parts, customer approval, invoice pending) with aging buckets; and WIP cost by department and cost type, with estimated P&L against quote value. Slicers filter by department, customer, status, and owner, and detail tables drill down to the individual work order.
Result
One place to see what's shipping, what's stuck and why, and which open jobs are losing money, from the company-wide view down to a single work order.
  • Operations Overview
  • On Hold Overview
  • WIP Overview

Recreated with sample data. The live reports use confidential company data.

NTSB aviation safety analysis In progress

Goal
A sandbox for trying new Power BI techniques on a large, messy, real-world dataset: about 47,000 NTSB aviation events from 2000 to today.
Approach
Wrote a script to pull event data from the NTSB's public data, then grouped the free-text probable-cause narratives into eight primary cause categories, tracking how many events could be categorized (83%) as its own KPI. Result
A working analysis of 25+ years of aviation events, and my test bed for new visuals, DAX patterns, and modeling ideas before I use them at work.

Personal project · Tableau · Public data

NFL Draft ROI

Goal
Answer a question I care about with data: which NFL teams get the most value from their draft picks?
Approach
Built a Value Over Expected (VOE) metric from Pro Football Reference draft data (1990–2025): each player's career Approximate Value minus the expected career value for their draft round, using only classes old enough for careers to be complete. Every pick is classified as a steal, expected, or bust. An overview dashboard compares all teams and positions, and an interactive Team Explorer shows any team's hit rate, VOE trend, position strengths, and biggest steals and busts.
Result
A public, interactive Tableau dashboard covering 35 years of drafts, from league-wide patterns like which positions return the most value in each round, down to individual players.
  • Overview dashboard
  • Team Explorer dashboard
  • Position value by round

Real dashboards on public data, published on Tableau Public.
