About

Systems thinker who measures results in hours saved

I'm Xavier Denson, a systems and automation-focused IT professional with a B.S. in Software Development from Green River College and a Google Advanced Data Analytics certificate. My background spans software support, QA automation, and development, so I understand both how systems are built and how they break.

At Aero Controls I design the automations and integrations that connect our business systems: a Jira REST API workflow that provisions and deactivates user accounts straight from tickets, a PowerShell / SQL Server pipeline that runs, validates, and moves data between systems, and, increasingly, Power BI reporting built on that data. I also administer Azure / Entra ID identity and access alongside Intune and Microsoft 365.

Before that I built Selenium and Python test automation at Heritage Bank while working with regulated financial data, and Java / Spring Boot APIs as an intern at Costco. I use AI-assisted development (Claude Code and MCP tooling) to build and debug faster, and I validate its output against source systems before anything reaches production.

I'm also available for freelance work in Power BI, SQL reporting, and workflow automation.

Work that saves real time

Highlights from my day job. Internal systems and data stay private, so these focus on the problem, the approach, and the result.

Automation · API Integration

Ticket-driven account provisioning

Problem
Setting up and deactivating user accounts was a ~20-minute manual process for every request, repeated across multiple systems.
Approach
Built a cross-system workflow that pulls tickets from the Jira REST API and drives account provisioning and deactivation with Java / Selenium and PowerShell.
Result
~20 minutes → one automated action, with consistent setup and fewer missed steps.
  • Jira REST API
  • PowerShell
  • Java
  • Selenium
Data Pipeline · SQL

Automated SQL data pipeline

Problem
Recurring data pulls and hand-offs between systems ate hours of manual work every week and left room for errors.
Approach
Built a scheduled PowerShell pipeline that runs SQL Server queries, validates the results, and exchanges the data with downstream systems.
Result
~4 hours/week (~200 hours/year) eliminated, with built-in validation for accuracy.
  • PowerShell
  • SQL Server / T-SQL
  • Task Scheduler
Business Intelligence · Power BI

Power BI reporting

Problem

Approach
Building Power BI reports and dashboards on top of the SQL Server data I already manage and automate: shaping and modeling the data, writing measures, and turning recurring requests into dashboards people can check themselves.
Result
Self-serve visibility for stakeholders and leadership, backed by the same validated pipeline data.
